Pourquoi Spiritty surpasse les outils existants

Chaque détail a été pensé pour respecter l'ergonomie sacrée du terminal Linux et accélérer les opérations de production.

🖥️

Split-Screen & Zéro Pollution

Votre shell à droite reste 100% interactif en continu (bash, zsh, fish). Aucune commande n'est insérée en douce ni cachée avec des sentinelles visibles dans votre PTY.

🛡️

Human-in-the-Loop & Sécurité

Aucune commande ne tourne sans votre accord explicite. Classification stricte des risques (Safe, Sudo, Risky) et modes d'approbation ajustables en une touche (F3).

🌐

Contexte Hôte & Détection SSH

Surveillance temps réel sous le PTY : Spiritty détecte vos connexions SSH, profile la distribution distante (Debian, Ubuntu, Arch...) et bascule instantanément son prompt.

🧠

Multi-Providers & LLMs Locaux

DeepSeek V4.1 Flash, Claude 3.7 Sonnet, Gemini 2.5, Grok, OpenAI, mais aussi vos serveurs locaux Ollama et LM Studio pour une confidentialité totale.

🔌

Support Protocole MCP

Intégrez vos serveurs MCP (Model Context Protocol) en JSON-RPC pour connecter Docker, Kubernetes, bases de données et outils custom via la modale Ctrl+M.

📊

Métriques Réelles & Coûts Live

Suivi exact du débit (tokens/s réels), décompte précis des fenêtres de contexte et estimation en direct du coût de votre session au centième de centime.

Installez Spiritty facilement

Téléchargez le binaire précompilé officiel ou compilez depuis les sources Cargo en quelques commandes.

Recommandé

1. Installateur One-Line

Détecte automatiquement votre architecture, installe le binaire dans ~/.local/bin et configure le lanceur bureau avec icône.

curl -fsSL https://spiritty.ai/install.sh | bash

2. Compilation depuis les Sources

Vous avez Rust installé ? Clonez le dépôt et construisez le binaire autonome optimisé en une minute chrono.

git clone https://github.com/xorne-git/Spiritty.git
cd Spiritty && cargo build --release

3. Archives Binaires Directes

Téléchargez directement les archives tarball légères pour Linux x86_64, aarch64 ou macOS Apple Silicon depuis GitHub Releases.

Voir les releases GitHub →

Raccourcis essentiels

Restez au clavier : tout est accessible en une combinaison de touches intuitive.

Raccourci Action Utilité
Ctrl + A Bascule de focus Passe instantanément du panneau Chat au shell Terminal natif
Alt + 1..9 Exécuter proposition N Injecte et exécute la commande #N suggérée par Spiritty
Alt + D Diagnostic proactif Analyse immédiatement la dernière commande shell échouée dans le PTY
F2 / Ctrl + P Configuration & Modèles Changez de provider, de modèle ou de clé API à la volée
F3 Niveau d'approbation Basculez entre Safe, Sudo, Yolo et Strict
Ctrl + M Gestionnaire MCP Inspectez, activez ou configurez vos serveurs et outils MCP
Ctrl + H Historique des sessions Naviguez, restaurez ou compactez vos conversations archivées
